# RMUTP Login UI Design

A university login page UI design created using Figma.

## Project Overview

This project focuses on designing a login interface for Rajamangala University of Technology Phra Nakhon (RMUTP), with separate layouts for Desktop and Mobile devices.

## Design Tools
- Figma

## Design Versions

### 1. Desktop Design
- Designed for desktop screen sizes.
- Two-column layout.
- Purple university-themed color scheme.

### 2. Mobile Design
- Designed for mobile screen sizes.
- Vertical layout optimized for smaller screens.
- Responsive UI concept.

## Design Features
- Email and Password input fields
- Login button
- Forgot Password link
- Sign Up link
- University branding
